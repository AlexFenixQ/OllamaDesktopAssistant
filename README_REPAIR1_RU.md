# Hotfix 4 Repair 1 — Ollama Desktop 0.1.25

Исправлен отказ `Unknown existing version: src/OllamaDesktop.Core/DraftToolRecovery.cs` при применении Hotfix 4. Исходная версия не содержала этот файл; предыдущее сравнение `$null` с пустой строкой ошибочно отклоняло корректную установку.

Исправленный `Apply-Hotfix4.ps1` допускает **отсутствующий** новый файл, но отклоняет существующий неизвестный файл и частично применённый патч. Контроль SHA-256 исходных и обновлённых файлов, резервное копирование и откат сохранены.

Запускайте только `Apply-Hotfix4.ps1` из распакованного полного архива с помощью команды из ответа. Обычная Windows PowerShell 5.1; без администратора и без глобальной смены политики исполнения.

При успехе исходники будут обновлены, выполнены сборка и тесты и запущена штатная установка. При ошибке данные пользователя не удаляются. Если ошибка `Unknown existing version` повторится, нельзя автоматически считать имеющийся файл безопасным: понадобится диагностика хеша.

**Не проверено**: исполнение PowerShell на Windows, сборка WPF и реальные запросы облака.
