# Ollama Desktop

Windows-приложение для Ollama Cloud: чаты, проекты, вложения и создание документов.

**[Скачать установщик и полный архив](https://github.com/AlexFenixQ/OllamaDesktopAssistant/releases)** · [Инструкция на русском](README_RU.md) · [Безопасность](SECURITY.md)

Версия 0.1.30: интерфейс со сворачиваемой боковой панелью, проекты с чатами и обновления стабильного/бета-канала по подписанным манифестам.

Для обычного пользователя достаточно установщика. Он включает .NET; Office и локальная Ollama не требуются. Для облачных ответов нужен личный ключ Ollama и доступ в интернет.

Репозиторий не содержит ключей, переписок, пользовательских вложений или закрытого ключа подписи обновлений. Открытая публикация исходников сама по себе не предоставляет лицензию на их использование: отдельная лицензия на код пока не выбрана владельцем. Лицензии сторонних компонентов приведены в THIRD_PARTY_NOTICES.md.

Владельцу: готовый `Start.ps1` проверяет пакет, готовит официальный SDK, собирает и тестирует Windows-приложение. Подробности — в README_RU.md.
