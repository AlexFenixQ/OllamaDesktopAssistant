# Ollama Desktop

Настольный клиент для Ollama Cloud на C# / .NET 10 / WPF.

Версия 0.1.30 готовится: новый интерфейс, проекты и проверяемые обновления стабильного/бета-канала. Установщик будет опубликован после Windows-проверок.

Ключи, история и пользовательские файлы хранятся локально и не входят в репозиторий.
