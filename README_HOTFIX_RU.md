# Ollama Desktop 0.1.25 — hotfix определения установленной версии

Исправление относится **только к исходникам версии 0.1.25**; номер релиза приложения не меняется. Исправлены списки распознаваемых установленных версий в `Start.ps1` и `scripts/Update-Installed.ps1`, добавлена 0.1.24. Вся поставка представляет полный исходный проект.

1. Проверяются SHA-256 исходных файлов именно оригинального выпуска 0.1.25 и файлов исправления.
2. Три изменяемых файла (`Start.ps1`, `Update-Installed.ps1`, `MANIFEST.json`) резервируются под `artifacts/hotfix-backup-*`.
3. Изменения применяются, их контрольные суммы проверяются.
4. Запускается штатный `Start.ps1`: тесты, сборка и обновление с подтверждением.

Если файл изменён или неизвестен, обновление останавливается. Для отката только этого исправления (не установленного приложения) включён `Rollback-Hotfix.ps1`.

**Не проверено:** выполнение PowerShell и Inno Setup на реальном Windows. Не удаляйте сохранённые резервные копии.
