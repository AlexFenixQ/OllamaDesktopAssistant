# Проверка Ollama Desktop — выпуск 0.1.29

Дата: 7 ноября 2026. База: OllamaDesktopAssistant-0.1.28-Hotfix1-FullSource.zip. Задание: исправление подтверждённых ошибок и неработающих существующих функций без новых возможностей, с сохранением данных.

## Область проверки

В указанном каталоге и тестовом наборе обнаружено 65 файлов, включая 44 ZIP. Выполнена проверка CRC всех 51 ZIP/Office-контейнеров: повреждений не найдено. Подробно проверена актуальная полная база: C#, XAML, шаблоны, настройки сборки, зависимости, тесты, PowerShell и Inno Setup. Старые выпуски использованы как неизменяемые базы обновлений; исправления выпущены в новой версии. Старые версии по отдельности заново не собирались.

Диагностические архивы просмотрены по кодам ошибок и номерам версий, без раскрытия содержимого переписки. В них есть исторические VISION_EMPTY и TOOL_SPEC_JSON. Эти ошибки нельзя объявить навсегда устранёнными для любого ответа провайдера: проверены безопасная обработка, ограниченная коррекция структуры и сохранение уже готовых файлов. Реальный аккаунт Ollama не использовался.

Исходные архивы, тестовые документы и синхронизированный sources не изменялись. Приватные документы, история, API-ключи и диагностические журналы не включены в выпуск. Полное содержимое пользовательских финансовых документов не использовалось как эталон корректности расчётов; расчёты проверены на синтетических наборах с известными результатами.

## Что остаётся непроверенным и что сохранено как ограничение

1. Реальный доступ/баланс аккаунта и ответы моделей Ollama. Проверка выполняется пользователем в настройках с личным ключом; ключ в чат не нужен.
2. Установка, обновление, удаление и повторный запуск на отдельной чистой Windows без SDK/Office/Ollama. На рабочем компьютере новая версия не установлена автоматически. Windows 10 и ARM64 не проверены.
3. Нельзя гарантировать точность всех ответов модели, OCR/vision или форматирование каждого произвольного документа. Native/HTTP тесты не заменяют визуальную приёмку в Office/PDF-просмотрщике.
4. Существующие лимиты сохранены: 25 МиБ на файл, PDF до 100 страниц, визуальный вид первых 8 PDF-страниц с раскрытием пропусков; XLSX до 256 столбцов. Большие таблицы дают локальные агрегаты, а не произвольный поиск по любой строке. Устаревшие Office-форматы, макросы, пароли, автоматическая память, локальная модель и новые функции не добавлялись.
5. Установщик не подписан сертификатом издателя. Публичная поставка требует отдельной приёмки; не заявляется как проверенная для всех Windows.

## Применение и откат

Полный ZIP содержит готовый Setup и Install.ps1: SDK для установки не нужен. Сначала проверяется внешняя SHA-256 ZIP, затем внутренний MANIFEST.json. Install.ps1 проверяет известную базу, создаёт бэкап и запускает обновление. После проверки результата сохраняйте распакованную папку: в её artifacts находятся резервная копия и запись операции. scripts/Rollback-InstalledUpdate.ps1 восстанавливает предыдущее приложение, не заменяя пользовательские данные. Для первой установки предусмотрен scripts/Rollback.ps1 со штатным деинсталлятором. Исторические исходные архивы в D:/Work/IMPULS-ATOM/Development/Ollama Desktop сохранены.
