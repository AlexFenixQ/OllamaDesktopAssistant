# Синтетические данные для торговли и склада в стиле табличных выгрузок 1С

Файлы сгенерированы автоматически; не содержат реальные данные покупателей, работников или компаний. НЕ ЯВЛЯЮТСЯ оригинальными базами 1С 7.7 или 8, а лишь моделируют табличные экспорты.

`ODA_1C_Synthetic_StressTest_2026.xlsx`: 300 товаров, 1500 реализаций, 500 строк остатков с формулами доступного количества и стоимости остатков, сводная таблица.
`ODA_1C_120000_Synthetic_Sales.csv`: 120000 строк (UTF-8 BOM, разделитель `;`) для проверки скорости, парсинга, агрегирования и пакетной обработки.
`ODA_1C_Test_Data_Metrics.json`: контрольная сумма и контрольные итоги набора.

ВНИМАНИЕ: текущий чат-прототип имеет ограничение объёма извлечённого текста (600000 символов на запрос). Не загружайте 120000 строк в один запрос: это нагрузочный набор для разработки будущей пакетной обработки и агрегации, а не подтверждение её реализации.
