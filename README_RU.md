# Ollama Desktop 0.1.32

Готовое приложение Windows x64: установщик содержит .NET и встроенные FFmpeg/Whisper. Обычному пользователю не нужны Office, Git, SDK, терминал или локальная Ollama.

## Исправление форматов в 0.1.32

Обложки в M4A/MP3 распознаются как обложки, а не как видеодорожка: они не запускают поиск видеокадров и не мешают расшифровке аудио.

В 0.1.31 AVI уже был разрешён, но сборка FFmpeg содержала узкий набор декодеров. Дополнительно исправлена длительность AVI: неопознанные служебные потоки не должны удлинять распознанную видео/аудиодорожку; контрольные точки получают уточнённую длительность. Причина отказа пяти указанных пользователем AVI установлена локально: HEVC-видео и PCM μ-law в первой звуковой дорожке; декодер μ-law отсутствовал. В 0.1.32 расширены встроенные LGPL-декодеры/парсеры/демультиплексоры; включены μ-law/A-law, старые AVI-кодеки, AC-3/E-AC-3/DTS, MPEG-PS и программный AV1. Проверены полное локальное декодирование основных аудиодорожек всех пяти файлов без сохранения содержания, перемотка в середине и конце, уточнённая длительность и один видеокадр. Личные записи/кадры в облако не отправлялись; полная расшифровка пользовательских AVI в этой проверке не запускалась.

Изображения: JPEG/JFIF, PNG/APNG, GIF, WebP, BMP, TIFF/BigTIFF, HEIC/HEIF/AVIF, JPEG XL, JPEG 2000, ICO/CUR/ICNS, PSD/PSB, DDS/PCX/TGA, EXR/HDR, PNM и другие нативные растровые форматы, RAW/DNG/NEF/CR2/CR3 и поддерживаемые LibRaw камеры. JPEG XR/WDP/HDP читаются встроенным Windows WIC. Наличие расширения не гарантирует доступность каждого варианта кодека или каждой модели камеры.

PSD/PSB анализируется по сведённому изображению, ICO — по крупнейшему варианту. RAW/HDR преобразуется в обычное превью; точная фотографическая проявка/сохранение HDR не обещается. Оригинал остаётся без изменений. TIFF — до 48 страниц для отдельного файла при действующих ресурсных лимитах; встроенные изображения документов сохраняют отдельные ограничения.

Анимации GIF/APNG и доступные анимированные форматы: до 24 кадров равномерно по последовательности, с номерами кадров; если обработка идёт через многостраничный декодер, предел 48 кадров/страниц. Это выборка, не гарантированный непрерывный просмотр каждого момента. Превышение ресурсов/неизвестные варианты сообщаются явно. Небольшие изображения при подготовке кадров не увеличиваются до 1280 пикселей.

SVG/SVGZ — встроенный MSVG-рендерер без Inkscape/Ghostscript/сетевых загрузок. DTD, скрипты, foreignObject, внешние href/CSS, xml:base и внешние/встроенные ресурсы отклоняются. EPS/AI/PostScript, внешние делегаты и неизвестные проприетарные форматы не включены. Прямые MVG-команды не принимаются; MVG разрешён только как внутренний этап проверенного SVG.

Буквальная поддержка любого существующего формата невозможна: повреждённые, защищённые/DRM, неизвестные проприетарные данные, RAW от неподдерживаемых камер, потоки без достоверной длительности и превышающие ограничения записи могут не декодироваться. Фильтр «Все файлы» позволяет выбрать файл; приложение проверяет реальное содержимое. Прежние пределы сохранены: изображения/документы 512 МиБ, аудио/видео 2 ГиБ и 6 часов, кадр/изображение 40 Мп. Для контейнера с несколькими звуковыми дорожками обрабатывается первая (основная), наличие дополнительных явно указывается.

Проверки 0.1.32: 154 регрессии, реальные HEVC-HEIF и AV1, собственный синтетический RAW/DNG, GIF с последним кадром, безопасный SVG с отказом внешних ресурсов; отдельный рабочий процесс с полной русской ASR, отменой/продолжением и Windows JPEG XR. Новые облачные запросы для 0.1.32 не выполнялись. Чистая Windows без SDK и исчерпывающая матрица всех кодеков/камер не проверены. См. TEST_STATUS.json.

## Изменения интерфейса

Тёмная сине-графитовая тема в фирменном стиле: чаты и раскрываемые проекты слева, свободная область беседы, поле запроса внизу, панель файлов справа по кнопке. Единые векторные значки, чёткая иконка ламы, тематические меню/списки/полосы прокрутки. Настройки и информационные окна используют общий стиль. Кнопка остановки появляется во время работы; кнопка отправки возвращается после завершения. Сохранение результата подтверждается строкой состояния. Светлая тема сохранена.

## Аудио и видео

До 50 файлов на запрос. Документ/изображение/ZIP — до 512 МиБ; отдельный аудио/видеофайл — до 2 ГиБ и 6 часов. Добавьте запись кнопкой «+» или перетаскиванием. При первом импорте автоматически загрузится Whisper Small (~466 МиБ); можно выбрать Medium (~1,5 ГиБ, медленнее) в настройках. Модель проверяется по SHA-256. Загрузка и распознавание требуют свободного места; модель хранится отдельно от истории и установочных файлов.

Основная звуковая дорожка целиком обрабатывается локально последовательными частями по 5 минут без отбора только начала/конца. Текст с временными отметками сохраняется после каждой части. «Стоп» сохраняет исходную копию и готовую расшифровку; «Продолжить» в панели файлов продолжает с сохранённой части, в том числе после перезапуска. Незавершённая запись не выдаётся за полный результат. TXT можно открыть отдельно.

После подготовки напишите, например: «Составь подробный отчёт конференции: темы, решения, задачи, ответственные, сроки и открытые вопросы». Для отчёта Ollama Cloud последовательно получает все блоки текста, затем объединяет их; начало/конец записи не отбрасываются по лимиту контекста. Создаются полный TXT и настоящий проверенный DOCX. Имена, сроки и решения не должны выдумываться. Если источник их не содержит, указывается «не указан».

Видео: распознаётся весь звук; кадры выбираются равномерно по всей записи и по сменам сцен (до 64 подготовленных кадров на видео). В один облачный отчёт передаётся не более 64 кадров суммарно, отбор раскрывается в предупреждениях. Краткие события между кадрами могут быть пропущены. Опция «Фото» управляет отправкой кадров. Надёжного определения личности говорящего нет; автоматическая расшифровка может ошибаться, а тишина/неразборчивый звук отмечаются. «Полная» означает обработку всей временной шкалы, а не гарантированное безошибочное восстановление каждого слова.

Контейнеры: WAV, MP3, M4A/AAC, FLAC, OGG/Opus, MP4/MOV, MKV/WebM, AVI, WMV/WMA, MPEG/TS. Поддержка зависит от кодека: встроены распространённые H.264/HEVC/MPEG-4/VP8/VP9 и аудиокодеки; AV1 поддерживается программным декодером libaom; DRM и некоторые редкие/проприетарные варианты недоступны. Повреждённая или неподдерживаемая запись отклоняется, оригинал не изменяется. Если видео без звука, это явно сообщается.

Для документов сохраняются защитные ограничения: PDF до 100 страниц, изображение до 40 Мп, до 400 000 извлечённых знаков на документ и 600 000 суммарно; превышение не скрывается. ZIP ограничен 1 ГиБ распакованных данных, 50 поддерживаемыми файлами, 512 МиБ на элемент и защитой от опасных путей/архивных бомб. Большие медиазаписи добавляйте отдельно от ZIP.

## Данные и облако

История, проекты, черновики, вложения и результаты: `%LOCALAPPDATA%\OllamaDesktopAssistant\Data`. Ключ защищён Windows DPAPI для текущей учётной записи. Модели речи: `%LOCALAPPDATA%\OllamaDesktopAssistant\Models\Speech`. Установка/откат меняет программу, сохраняя пользовательские данные. Данные не включены в публичный архив. Скрытой телеметрии нет.

Сырой звук/видео не отправляется в Ollama: локально готовится текст, а по настройке — выбранные кадры. Облачный отчёт требует личного ключа, согласия на передачу и доступного лимита аккаунта; он может расходовать много запросов на длинных записях. Без облака можно подготовить локальный TXT. При сетевой ошибке/лимите повтор запускается вручную; расшифровка и созданные файлы сохраняются.

## Обновление и откат

Для установленной 0.1.31: закройте приложение и запустите `Update.ps1` из проверенного полного архива. Скрипт проверит версию/файлы/подпись, сохранит резервные копии программы и Data, обновит без окон установщика и запустит приложение. Неизвестные или изменённые установки не перезаписываются. Для новой установки: `release\OllamaDesktop-0.1.32-win-x64-Setup.exe`.

В приложении доступны стабильный/бета-канал, автоматическая проверка при запуске и каждые 6 часов, предложение обновления и установка по нажатию. История/ключ в GitHub не передаются. Манифест обновления подписан закреплённым RSA-ключом; сертификата Authenticode издателя нет. Не отключайте защиту Windows.

Чтобы откатить последнее обновление, закройте приложение и выполните из папки извлечённого архива:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Rollback-SilentUpdate.ps1
```

Скрипт найдёт последнюю проверенную резервную копию и попросит ввести ДА. Откат вернёт программу; историю, ключ и новые пользовательские файлы не заменит старой копией. Для исходников отдельные Apply-SourceUpdate/Rollback-SourceUpdate проверяют базовую версию и хеши; незнакомые папки не перезаписываются.

## Сборка владельцем

`Start.ps1` подготавливает закреплённый SDK из официального источника и собирает приложение; запускать его для использования готового установщика не требуется. `scripts\Build.ps1` выполняет 154 теста и 17 WPF-проверок; `scripts\Package.ps1` собирает Inno Setup. Полный архив уже содержит готовые медиабиблиотеки и соответствующие исходные архивы. При сборке из GitHub отсутствующие библиотеки собираются автоматически из закреплённых исходников с w64devkit; компилятор конечным пользователям не устанавливается. Дополнительная реальная локальная медиапроверка: `scripts\Test-Media.ps1` (первая загрузка Small ~466 МиБ). Личные данные и облачные запросы в неё не входят.

## Фактические проверки

См. TEST_STATUS.json и verification. Проверены 154 автоматических теста, WPF smoke, полный русский синтетический звук/видео, отмена и продолжение в новом процессе, реальный облачный отчёт с TXT+DOCX. Запись длится 37 секунд: шестичасовая запись, Medium и файл 2 ГиБ целиком не прогонялись. Чистая Windows без SDK/Office/Ollama, Windows 10/ARM64 и переходы DPI между мониторами не прошли отдельную приёмку. Исходный пользовательский звук проверяет владелец.
