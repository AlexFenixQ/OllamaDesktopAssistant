# Исправление 0.1.25 Hotfix 2

Исправлен повторный запрос корректной JSON-структуры параметров документа при ошибке TOOL_SPEC_JSON; число проверяемых попыток увеличено до шести. Изменены только цвета тёмной темы, светлая тема оставлена без изменений. Исправлен перечень допустимых установленных версий для обновления по той же версии 0.1.25.

Архив содержит полные исходники и автоматические сценарии применения/отката. Установку через Inno выполняет Apply-Hotfix2.ps1 с полным резервированием установленной программы. Перед запуском необходимо закрыть приложение.

Проверки в этом окружении: целостность архива, исходные хеши заменяемых файлов, JSON и статический анализ. Сборка WPF, тесты Windows и реальный облачный запрос должны быть проверены на компьютере владельца.

Это повышение устойчивости генерации, но не гарантия качества произвольных ответов облачной модели: при повторном невалидном JSON файл не будет создан и пользователь увидит ошибку.
