# Ollama Desktop 0.1.25 — Hotfix 4

Исправление ситуации, когда модель печатает JSON в блоках Markdown вместо вызовов функций. Новый модуль `DraftToolRecovery` извлекает только JSON из ответа модели, проверяет явное намерение пользователя создать файлы, нормализует известные схемы Word/Excel/PowerPoint и передаёт параметры в существующий `ArtifactService`, который валидирует и создаёт настоящие документы. Если данные недостаточны, создание отклоняется с кодом ошибки. ZIP созданных файлов собирается штатной функцией.

Только при подтверждении пользователя: `Apply-Hotfix4.ps1`. Проверка SHA-256 текущих файлов, резервное копирование, сборка и тесты перед заменой установленного приложения. Никакого редактирования вручную.

**Не проверено:** компиляция WPF на Windows и реальные запросы Ollama Cloud. Эту версию нельзя считать гарантированно работающей до прохождения Windows-тестов.
