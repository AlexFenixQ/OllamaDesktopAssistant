# Ollama Desktop 0.1.25 — Hotfix 3

Исправление VISION_EMPTY при анализе архива с изображениями. Если визуальная модель возвращает пустой ответ, соответствующие изображения явно помечаются как нераспознанные. Анализ документов с уже извлечённым текстом и запрос создания файлов продолжаются. Для запроса только об изображении без пригодного текста ошибка VISION_EMPTY сохраняется, чтобы не выдумывать содержимое.

Применение: `Apply-Hotfix3.ps1` после проверки контрольной суммы внешнего ZIP. Скрипт делает проверяемую копию заменяемых исходников, запускает Build.ps1, Package.ps1 и Update-Installed.ps1. Ключ Ollama не требуется в терминале.

Откат исходников: `Rollback-Hotfix3.ps1` внутри папки `artifacts/hotfix3-backup-*` новой рабочей копии. Откат отдельно установленного приложения — прежним сценарием `scripts/Rollback-InstalledUpdate.ps1`, при наличии проверенной резервной копии.

**Тесты:** проверена структура ZIP и соответствие хешей в метаданных. Windows-сборка и реальное взаимодействие с Ollama Cloud должны быть проверены на Windows.
