# Исправление сборки 0.1.28 — Hotfix 1

Этот пакет предназначен для рабочей копии исходников `0.1.28`, уже созданной основным скриптом. Первоначальный проект и установленное приложение не удаляются.

## Причина

В `Start.ps1` и `scripts/Update-Installed.ps1` список предшествующих установленных версий обрывался на `0.1.26`, поэтому реальная установленная `0.1.27` ошибочно отклонялась до сборки. В исправлении обе проверки включают `0.1.27`. Кроме того, `Verify-Package.ps1` теперь предварительно подтверждает, что обе проверки распознают все предшествующие версии из данного выпуска.

## Как применить

Используйте точную PowerShell-команду из ответа ChatGPT: она проверит SHA-256 скачанного ZIP, распакует его в отдельную папку и запустит `Apply-Hotfix1.ps1`. Скрипт проверяет исходники и новую копию, создаёт проверенный резервный набор четырёх файлов, применяет обновление, сверяет весь `MANIFEST.json` и запускает штатный `Start.ps1`.

Исправление не меняет номер версии приложения (`0.1.28`), не требует переустанавливать SDK, не меняет учётные данные и переписки. Если установленная версия не входит в проверенный набор, защитная остановка сохранится.

## Ожидаемый результат

Сборка и тесты, создание `artifacts\installer\OllamaDesktop-0.1.28-win-x64-Setup.exe`, подтверждение обновления установленного приложения. Если код завершится с ошибкой, сохраните диагностический ZIP из папки `artifacts`.

## Откат исправления исходников

Команда PowerShell:

```
& {
  $root = Join-Path $env:LOCALAPPDATA 'OllamaDesktopAssistant\Source\0.1.28\artifacts'
  $b = @(Get-ChildItem -LiteralPath $root -Directory -Filter 'hotfix1-backup-*' | Sort-Object LastWriteTime -Descending)
  if ($b.Count -eq 0) { throw 'Резервная копия не найдена.' }
  & powershell.exe -NoProfile -ExecutionPolicy Bypass -File (Join-Path $b[0].FullName 'Rollback-Hotfix1.ps1')
}
```

Этот откат изменяет **только четыре исходных файла**; он **не откатывает установленное приложение**. Для отката приложения после успешного обновления используйте `scripts\Rollback-InstalledUpdate.ps1` из источников `0.1.28`, если имеется проверенная резервная копия. Не удаляйте файлы вручную.

## Проверки и ограничения

Текстовый анализ пакета, контрольные суммы и моделирование совместимости выполнены. Реальный запуск PowerShell 5.1, WPF, установка на Windows 10 и облачные запросы здесь не выполнялись.
